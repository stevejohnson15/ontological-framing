# Ontological Framing in LLMs

*Simples Arranged Promptwise: Probing Quantifier Variance in Large Language Models*

Tier 1 probing study: do LLM existence verdicts on composition vignettes track the
described scenario or the ontological framing (nihilist / universalist / common-sense)?

- `plan/DESIGN.md` — canonical design (what & why, all tiers)
- `plan/PLAN.md` — milestones and build status (how & when)
- `research/` — reading-list PDFs (local only, gitignored) + `research/README.md` index

| Dir | Purpose |
| --- | --- |
| `battery/` | vignette templates, framings, paraphrases, `build.py` → `items.jsonl` |
| `harness/` | model runs, `models.yaml`, translation-fidelity graders |
| `analysis/` | prereg'd mixed-effects analysis, paraphrase-consistency gating |
| `interp/` | RQ4 probes, RSA/CKA, activation patching |
| `prereg/` | OSF preregistration draft |
| `results/` | outputs, figures, tables |
